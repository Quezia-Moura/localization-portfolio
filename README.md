# Localization Portfolio App

A personal portfolio project focused on software localization and multilingual user experiences.

The goal of this project is to explore how digital products can be adapted for different languages and cultures, with attention to clear communication, natural language, and consistency across interfaces.

## Current Status

This project is currently in development.

The initial setup includes a bilingual React application with English and Brazilian Portuguese (pt-BR).

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- i18next
- react-i18next

## Languages

- English (en)
- Brazilian Portuguese (pt-BR)

## Getting Started

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project folder:

```bash
cd localization-portfolio-app
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Project Goals

- Build and test multilingual user interfaces.
- Practice software localization with English and Brazilian Portuguese.
- Explore translation quality, terminology, and linguistic consistency.
- Document localization and linguistic QA decisions.
